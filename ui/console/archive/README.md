# Archived Frontend Screens

These files are kept for historical reference from the original DialForge
product surface, but they are not part of the current DealPilot frontend focus.

DealPilot's near-term frontend direction is:

- active sales calls
- power dialing
- contacts and CRM context
- call history
- post-call summaries and analysis
- company AI / RAG configuration
- core settings and profile
